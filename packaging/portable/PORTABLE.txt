DuctZip portable package
=========================

What this is
------------
A no-install distribution of DuctZip: the CLI, the optional GUI, and the
Windows Explorer integration commands, plus documentation and license.

Requirements
------------
- Windows 10/11.
- Python 3.11 or newer on PATH (python / pythonw).
- No 7-Zip installation required: this package bundles the 7-Zip console
  backend in vendor\7zip. A system-installed or explicitly configured backend
  still takes priority (explicit flag > DUCTZIP_7Z_PATH > bundled copy >
  standard install locations > registry > PATH).
- GUI only: PySide6 in the active Python environment
  (python -m pip install PySide6).

How to run
----------
- CLI:        ductzip.cmd doctor
              ductzip.cmd extract "archive.zip" --output "out dir"
- GUI:        DuctZip GUI.cmd
- Explorer:   ductzip.cmd shell register     (current user, no elevation)
              ductzip.cmd shell unregister   (exact reversal)

When registered through these launchers, the Explorer context-menu verbs
run via ductzip.cmd, so a console window accompanies each verb invocation
(the launcher is a batch script). No pip install is needed for the verbs
to find the package.

Settings and data
-----------------
The launchers keep DuctZip's settings file beside this file
(settings\settings.json) so the package stays portable. Set
DUCTZIP_SETTINGS_PATH before launching to use another location.

Extraction outputs, logs, and the registry keys created by
"shell register" are the only things DuctZip writes outside this folder.

7-Zip backend
-------------
This build bundles the official 7-Zip console backend (7z.exe + 7z.dll,
version 26.03 x64) in vendor\7zip, so extraction works on a machine with no
7-Zip installed.

Note that upstream 7-Zip does not Authenticode-sign its Windows binaries, so
the bundled files carry no publisher signature. They were verified by TLS
transport plus the SHA-256 digest published in the upstream release metadata;
the exact hashes and the full verification chain are recorded in
THIRD_PARTY_NOTICES.md. If you require a signed backend, point DuctZip at your
own copy with --sevenzip or DUCTZIP_7Z_PATH.
