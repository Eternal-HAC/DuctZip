# DuctZip 安全与隐私说明

更新时间：2026-09-19（v0.7）

本文档说明 DuctZip 当前版本实际读取、写入、执行和记录的内容，以及已知的安全边界。描述以当前代码和测试为准；与实现不一致时以代码为准并应修正本文档。

## 本地-only 承诺

DuctZip 不做任何网络行为：没有遥测、没有自动更新、没有云同步、没有任何下载功能。除了解压时调用本机 7-Zip 可执行文件外，DuctZip 不启动其他进程。增加任何网络行为都需要用户明确批准。

## 读取

- 压缩包文件（用户显式选择或通过右键菜单传入）。
- 7-Zip 后端可执行文件（调用时）。
- 用户设置文件：`%APPDATA%\DuctZip\settings.json`（可用环境变量 `DUCTZIP_SETTINGS_PATH` 覆盖，供便携模式和测试使用）。设置损坏时重置为默认值，损坏文件备份为 `settings.json.corrupt`。
- 注册表（仅 `ductzip shell register/unregister/status` 命令，且仅限 HKCU 下 DuctZip 自有键）：用于发现已安装的 7-Zip 和读写右键菜单注册。
- 后端发现会读取环境变量 `DUCTZIP_7Z_PATH` 和常见安装位置。

## 写入

- 解压输出只写入用户指定的输出目录（Smart Output 会基于该目录推导最终目录，但不会写出到该目录树之外）。引擎在每次实际解压前对真实条目做路径校验：拒绝绝对路径、盘符相对路径、`..` 穿越、`.`/空路径段、UNC 与 `\\?\` 前缀、Windows 保留设备名（CON/PRN/AUX/NUL/CONIN$/CONOUT$/COM1-9/LPT1-9，含带扩展名和尾随点/空格的变体）。校验一律以后端自行 list 的条目为准，任何调用方传入的列表都不能替代。
- 设置文件（见上）。
- 右键菜单注册（仅当用户运行 `ductzip shell register`，仅 HKCU，可精确撤销）。
- 不写入系统目录、不需要管理员权限。

## 执行

- 7-Zip 后端（`7z.exe`/`7zz.exe`，自动发现或用户指定）。取消解压时会按 terminate → wait → kill → wait 链终止并回收子进程，所有路径（完成、失败、取消、被遗弃的生成器）都确定性回收，不留孤儿 7-Zip 进程。
- 安装/便携包注册表动词通过 `"<python/pythonw>" -m ductzip shell <verb> "%1"` 调用本程序自身。

## 密码处理

- 密码只存在于内存：从命令行参数、`--password-prompt` 或 GUI 密码框读取，传给后端进程的命令行参数，随后丢弃。
- 密码**永不写入**设置文件、日志、进度事件、任务错误或持久化的批量日志。批量队列在记录后端原始失败输出前先做密码脱敏。
- CLI 出错输出中不包含密码（有专门的回归测试验证错误密码不会出现在输出中）。
- 设置数据模型中不存在密码字段（有测试保证）。

## 日志与错误消息

- 用户可见的错误消息是稳定的本地化短句（如「压缩包可能已损坏。」），不包含后端原始输出；原始输出保留在异常的 `.detail` 属性中供调试，不直接展示。
- GUI 日志窗口和 CLI `--verbose` 用于诊断；批量结构化日志持久化状态迁移与批次起止，不持久化进度事件，密码已脱敏。
- 已知残留：`extract_with_progress` 失败的 `ProgressEvent(message=...)` 携带后端原始输出片段，供 GUI 日志/调试展示，批量层已对其脱敏。

## Mark-of-the-Web (MOTW)

**当前状态：未实现，属于已声明的暂缓项**（阻塞于 LONG_TASK.md §10.2 #5 人工决策：传播行为、支持的系统/文件系统边界、不完整实现是否阻塞 v1.0）。DuctZip 目前不会读取、传播或清除解压产物的 MOTW（`Zone.Identifier` NTFS 备用数据流）。从不信任来源下载的压缩包解压后，其产物不会继承来源的 Mark-of-the-Web 标记。决策记录前请勿宣称已防护。

## 已知安全边界（不支持的能力，诚实声明）

- 压缩包内符号链接 / Junction / 重解析点：不支持、不做防护。7-Zip CLI 会按链接目标写入，CLI 层无法可靠拦截。解压不受信任来源的压缩包时请注意此边界（DD-012）。
- 压缩包在规划与解压之间被替换（TOCTOU）：引擎每次实际解压前重新 list 并校验，安全上以真实条目为准；但 Smart Output 的规划结果可能因此与最终落盘布局不一致（产品层面可接受，见 DD-012）。
- 超大列表/输出的资源上限：未实现硬性上限（ROADMAP 中列为 SHOULD 项）。
- MOTW：见上，未实现。

## 右键菜单注册安全

- 仅 HKCU（当前用户），不写 HKLM，不需要提权（DD-015）。
- 注册幂等；`unregister` 只删除 DuctZip 拥有的键值，在正常卸载/撤销后不需要手工清理注册表。
- 动词协议中的压缩包路径以带引号的 `"%1"` 传递，支持中文、空格路径；Explorer 多选时每个文件独立调用一次动词。

## 设置与安全相关的默认值

- 覆盖策略默认 `skip`；顶层冲突默认 `merge`；CLI `extract` 的 Smart Output 默认关（`--smart-output` 开启）；GUI 与批量默认开。以上均可通过 `ductzip settings` 或 GUI 设置页持久化，优先级：显式命令行参数 > 设置值 > 内置默认值。
- 设置中的 7-Zip 路径在写入时校验必须存在；之后失效时自动回退到正常发现流程而不是硬失败。
