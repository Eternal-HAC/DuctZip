# DuctZip 快速简历卡

## 1. 项目一句话定位

DuctZip 是面向 Windows 用户的轻量归档解压工具原型，通过统一 CLI/GUI 调用本地 7-Zip，改善解压目录、冲突处理和错误提示体验。

## 2. 当前项目阶段

- 当前稳定提交：v0.3，提交 `a45e8b8`，已包含 PySide6 GUI 原型。
- 当前开发版本：v0.5 批量解压（队列核心 + CLI `batch-extract` + GUI 批量工作流）已实现并通过全部 144 项测试，但仍处于未提交工作区。
- CLI 已可运行（含批量命令）；GUI 代码已存在，可选 PySide6 依赖在本机已安装，GUI 测试以 offscreen 方式运行。
- 当前没有安装包、Git Tag 或正式 Release。
- 压缩、Windows 右键菜单和内置 7-Zip 后端仍未完成。

## 3. 当前已确认功能

- CLI 提供 `extract`、`list`、`test`、`doctor` 命令，并支持密码、进度、取消及详细输出。
- 借助 7-Zip 后端解压 ZIP、7z、RAR；真实后端集成测试已通过。
- 中文路径、空格路径、加密 7z 和错误密码已有测试覆盖。
- 支持 `skip`、`overwrite`、`rename` 文件覆盖策略。
- 解压前检查路径穿越条目，阻止向目标目录外写入。
- 对缺少压缩包、缺少后端、损坏包、密码、格式和权限等错误进行归一化。
- GUI 原型包含文件选择/拖入、内容预览、密码输入、进度、取消和打开输出目录；预览在后台线程加载并丢弃过期结果，窗口关闭对有界回收后台线程。
- Smart Extraction 能避免唯一同名顶层目录重复嵌套，并处理顶层目标冲突。
- 批量解压：CLI `batch-extract` 多包共享输出根（退出码 0/1/130/2，支持 `--retries`）；GUI 队列列表逐任务状态/进度/错误，重试、合法移除、取消当前/全部、双击打开最终输出目录。
- 稳定化：取消无输出后端秒级生效且子进程全路径回收；路径校验拦截 Windows 保留设备名；GUI 取消恰好上报一次、worker 异常可见。

## 4. 当前未完成或不能写入简历的内容

- 尚未实现：压缩、批量任务、Explorer 集成、文件关联、内置后端、安装包、MOTW、自动更新和 v1.0 发布。
- 压缩包内符号链接 / Junction / 重解析点解压不做防护，属于当前不支持的能力（已在文档中诚实声明）。
- ZIP、7z、RAR 的格式解析与压缩算法来自第三方 7-Zip，不是 DuctZip 自研能力。
- 文档提出的完整 Core、Security、ShellIntegration 分层是架构方向，并未全部落地。

## 5. 技术栈

- 编程语言：Python 3.11+
- GUI：PySide6
- 解压后端：7-Zip CLI（`7z.exe` / `7zz.exe`）
- 测试：Python `unittest`、假后端单元测试、真实 7-Zip 集成测试、PySide6 offscreen 测试设计
- 构建与项目配置：Setuptools、`pyproject.toml`
- 版本与文档：Git、Markdown 路线图/架构/设计决策/状态文档
- 许可证：MIT
- 当前无 CI 和正式发布流水线证据

## 6. 工程亮点

- Smart Extraction 根据压缩包顶层结构决定最终目录；仅当唯一顶层名称与目标目录同名时去除重复目录层级。
- 冲突检测聚焦顶层目标，提供 `merge`、`rename`、`cancel` 三种处理方式。
- 解压前列出条目并执行路径穿越检查，而非仅在 GUI 层提示风险。
- 将 7-Zip 返回结果映射为应用级异常，减少 CLI/GUI 对后端输出细节的依赖。
- 通过结构化生命周期/进度事件和取消信号，让 CLI 与 GUI 复用归档核心。
- 建立 107 项自动化测试：fake-backend 单元测试、真实 7-Zip 集成测试、引擎子进程生命周期测试、PySide6 offscreen GUI 测试（stub 引擎保证确定性），全部通过。

Smart Extraction 的当前边界：它不是智能内容识别或 AI 分类系统；不会批量规划任务，也不负责深层逐文件冲突分析。它主要依据顶层路径名称、目标目录名称和目标是否存在来决定目录及冲突策略。
