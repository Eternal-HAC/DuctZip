# DuctZip 快速简历卡

## 1. 项目一句话定位

DuctZip 是面向 Windows 用户的轻量归档解压工具（v1.0.0rc1 发布候选），通过统一 CLI/GUI 调用 7-Zip 后端，改善解压目录、冲突处理和错误提示体验；随包捆绑官方 7-Zip 控制台后端，未安装 7-Zip 的机器也能直接使用。

## 3. 当前已确认功能

- CLI 提供 `extract`、`list`、`test`、`doctor` 命令，并支持密码、进度、取消及详细输出。
- 借助 7-Zip 后端解压 ZIP、7z、RAR；真实后端集成测试已通过。
- 中文路径、空格路径、加密 7z 和错误密码已有测试覆盖。
- 支持 `skip`、`overwrite`、`rename` 文件覆盖策略。
- 解压前检查路径穿越条目，阻止向目标目录外写入。
- 对缺少压缩包、缺少后端、损坏包、密码、格式和权限等错误进行归一化。
- GUI 原型包含文件选择/拖入、内容预览、密码输入、进度、取消和打开输出目录；预览在后台线程加载并丢弃过期结果，窗口关闭对有界回收后台线程。
- Smart Extraction 能避免唯一同名顶层目录重复嵌套，并处理顶层目标冲突。
- 批量解压：CLI `batch-extract` 多包共享输出根（退出码 0/1/130/2，支持 `--retries`）；GUI 队列列表逐任务状态/进度/错误，重试、合法移除、取消当前/全部、双击打开最终输出目录。
- 稳定化：取消无输出后端秒级生效且子进程全路径回收；路径校验拦截 Windows 保留设备名；GUI 取消恰好上报一次、worker 异常可见。
- Windows 集成（v0.6）：`ductzip shell register/unregister/status` 在 HKCU 当前用户范围注册右键动词「解压到当前目录 / 解压到同名文件夹」与 Open-with 可见性；无需提权、不劫持默认程序、注册幂等且可精确撤销；已做真实注册表往返验证。
- 设置（v0.7）：`ductzip settings` 与 GUI 设置页共用同一模型，优先级为显式命令行参数 > 设置值 > 内置默认；设置文件原子写入，损坏时备份并重置默认值。
- 安全与隐私（v0.7）：安全强化后未知后端错误不再向用户暴露原始输出；密码不落盘、不进日志；全程无网络/遥测/自动更新；MOTW 传播把压缩包的 `Zone.Identifier` 复制到解压产物（尽力而为，非 NTFS 安静跳过）。
- 打包与分发（v0.7）：`scripts/build_portable.py` 生成便携 zip + SHA-256 + 构建清单，零下载、可重复；捆绑官方 7-Zip 26.03 控制台后端，构建时强制校验固定 SHA-256，篡改或缺失即拒绝打包。zip 内为单一顶层目录 `DuctZip-1.0.0rc1\`，已在隔离目录冒烟验证。
- 文档（v1.0）：`docs/USER_MANUAL.md` 覆盖安装/首次运行/CLI/GUI/右键菜单/后端/密码/冲突/安全限制/卸载/排错；`docs/SECURITY.md`、`docs/WINDOWS_INTEGRATION.md`、`docs/RELEASE_CHECKLIST.md` 齐备。

## 6. 工程亮点

- Smart Extraction 根据压缩包顶层结构决定最终目录；仅当唯一顶层名称与目标目录同名时去除重复目录层级。
- 冲突检测聚焦顶层目标，提供 `merge`、`rename`、`cancel` 三种处理方式。
- 解压前列出条目并执行路径穿越检查，而非仅在 GUI 层提示风险。
- 将 7-Zip 返回结果映射为应用级异常，减少 CLI/GUI 对后端输出细节的依赖。
- 通过结构化生命周期/进度事件和取消信号，让 CLI 与 GUI 复用归档核心。
- 建立 256 项自动化测试：fake-backend 单元测试、真实 7-Zip 集成测试、引擎子进程生命周期测试、批量队列状态机测试、安全对抗矩阵、PySide6 offscreen GUI 测试（stub 引擎保证确定性），全部通过。

Smart Extraction 的当前边界：它不是智能内容识别或 AI 分类系统；不会批量规划任务，也不负责深层逐文件冲突分析。它主要依据顶层路径名称、目标目录名称和目标是否存在来决定目录及冲突策略。
